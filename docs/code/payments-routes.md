# payments/routes.js

Маршрути оплати й сповіщень. Підключені за адресою `/api`. Усі вимагають входу (`requireUser`).

## Маршрути
| Метод і адреса | Що робить |
|---|---|
| `GET /payments/:id` | дані платежу для сторінки оплати; лише свій |
| `POST /payments/:id/pay` | оплатити (`payments.pay`) |
| `GET /notifications?page=N` | сповіщення з пагінацією і кількістю непрочитаних |
| `POST /notifications/read` | позначити всі прочитаними, відповідь 204 |

Сповіщення лежать тут, бо це дрібні маршрути без окремої області; їхня логіка в `notifications/service.js`.
