# test/e2e.test.js

**Наскрізний тест** (end-to-end): запускає справжній сервер і проходить повний сценарій через HTTP, як браузер. Методичка (5.6) вимагає щонайменше один такий.

## Сценарій
1. `/api/health` відповідає 200 і має `X-Request-Id`.
2. Продавець і учасник реєструються, адмін входить.
3. Повторна реєстрація того самого email: 409, формат problem+json, `type = /problems/email_taken`.
4. Лот з порожніми полями: 400 зі списком помилок.
5. Продавець створює лот з 3 фото (PNG 1×1).
6. Гість не бачить лот на модерації (404); не-адмін не бачить адмінське API (404).
7. Адмін схвалює, лот знаходиться пошуком.
8. Гість не може ставити (401). Учасник ставить: 201; той самий запит з тим самим ключем: 200, без дубля. Продавець на свій лот: 403.
9. Редагувати лот зі ставкою не можна: 409.
10. Таймер закриває лот, переможець оплачує. Продавець бачить адресу покупця. Чужий платіж: 404.
11. Учасник має сповіщення «ви виграли».

## Деталі
- `client(base)` імітує браузер: зберігає cookie між запитами.
- Сервер стартує на випадковому вільному порту (`listen(0)`) і зупиняється після тесту.
