# public/i18n.js

Усі тексти інтерфейсу двома мовами: `I18N.uk` і `I18N.en`.

## Як влаштовано
- Ключі однакові в обох мовах: `place_bid: 'Зробити ставку'` і `place_bid: 'Place a bid'`.
- Місця для підстановки в фігурних дужках: `min_bid: 'Мінімум {n} грн'`. Функція `t('min_bid', { n: 500 })` в `app.js` дає «Мінімум 500 грн».
- Групи ключів:
  - `n_...`: тексти сповіщень (`n_outbid`, `n_won`...);
  - `err_...`: помилки від сервера за кодом (`err_bid_too_low`...);
  - `rule_...`: помилки полів форм (`rule_required`, `rule_luhn`, `rule_max_bid`...);
  - `st_...`: статуси лотів.
- Кнопка мови в шапці (`UA` / `EN`) перемикає `state.lang`, вибір запам'ятовується в `localStorage`.

## Як додати новий текст
1. Ключ додається в `uk` і такий самий у `en`.
2. У `app.js` текст виводиться через `t('новий_ключ')`.
