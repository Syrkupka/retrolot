# seed.js

Заповнює базу демо-даними. Запуск: `npm run seed`.

## Що створює
- 8 категорій і 13 тегів;
- **50 користувачів**:
  - адмін `admin@retrolot.test` (пароль з `ADMIN_PASSWORD`, за замовчуванням `admin12345`);
  - `user1`-`user48@retrolot.test` з паролем `password123`; перші 15 продавці;
  - `blocked@retrolot.test`: заблокований, для демонстрації;
- **200 лотів**: 125 з торгами, що йдуть, 25 ще не почались, 35 завершених, 8 на модерації, 4 відхилені, 3 зняті;
- **1500 ставок**: суми в кожному лоті лише зростають, чверть лотів без ставок;
- платежі для завершених лотів: приблизно 70% оплачені, решта чекають оплати.

## Як працює
- **Не чіпає непорожню базу**. Параметр `--reset` (його додає `npm run seed`) спершу видаляє файл бази, потім `db.js` створює схему міграціями.
- **Випадковість фіксована** (`seed = 42`): щоразу виходять ті самі дані.
- Фото беруться з `public/img/seed/<категорія>-<річ>-<номер>.jpg`, у кожної речі свої 1-4 фото (Wikimedia Commons, автори й ліцензії в `public/img/seed/CREDITS.md`).
- Описи лотів складає `seed-texts.js`.
- Усе в одній транзакції: або вся база заповнилась, або нічого.
- Сповіщення позначаються як уже надіслані, щоб при першому старті сервер не розсилав сотні листів.

## Увага
`npm run seed` **видаляє** поточну базу: лоти й акаунти, створені вручну, зникнуть.
