# test/bid-worker.js

Допоміжний процес для тесту гонки в `bids.test.js`. Сам по собі не запускається.

## Як працює
1. Отримує з командного рядка: id учасника, id лота, суму і момент старту.
2. Відкриває **власне** з'єднання з тією самою тестовою базою.
3. Крутиться в порожньому циклі до моменту старту, щоб усі 8 процесів поставили в ту саму мілісекунду.
4. Викликає `placeBid` і друкує результат як JSON: `{"ok":true}` або `{"ok":false,"code":"bid_too_low"}`.

Тест збирає вивід усіх процесів і рахує, скільки ставок прийнято.
