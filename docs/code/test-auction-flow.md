# test/auction-flow.test.js

Тести того, що відбувається після торгів, і роботи з лотами. Викликають сервіси напряму.

## Що перевіряють
| Тест | Що доводить |
|---|---|
| lot ends by timer, winner pays once, seller sees contacts | таймер закриває лот; другий виклик нічого не робить; невірна картка відхиляється; оплата проходить один раз; продавець бачить контакти покупця, сторонній ні |
| unpaid lot goes to the next bidder and the non-payer is blocked | після терміну оплати: неплатника заблоковано, лот перейшов другому учаснику за його ставкою, заблокований не може ставити |
| edit and withdraw only before the first bid; hidden lots look missing | чужий лот не зняти; з ставками не зняти; знятий лот для сторонніх «не існує», продавцю видно |
| catalogue filters and pages on the server | пошук, ціна від, сортування і сторінки рахуються на сервері; неприпустиме сортування дає помилку |
| a leader blocked before the end is skipped right away | заблокованого лідера пропущено, лот одразу пішов наступному |

Термін оплати в тестах 1 год (`PAY_WINDOW_HOURS = '1'`), а час передається явно (`now + 2 * 3600000`), щоб не чекати годину.
