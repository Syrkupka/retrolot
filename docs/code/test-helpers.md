# test/helpers.js

Спільні функції для тестів.

## Що всередині
- **`useTempDb()`**: створює тимчасову папку і вказує в `DB_FILE` та `UPLOAD_DIR` шляхи туди. Тести **ніколи не чіпають** робочу базу `data/auction.db`. Треба викликати до першого `require('../db')`.
- **`fixtures()`**: додає категорію і повертає помічники:
  - `user(email, role)`: створює користувача, повертає id;
  - `lot(sellerId, options)`: створює лот (за замовчуванням активний, старт 100, крок 10, кінець через годину);
  - `db` і `now`.

Кожен файл тестів працює в окремому процесі (так запускає `node --test`), тож у кожного своя чиста база.
