# scripts/check.js

Перевірка синтаксису: `npm run lint`.

## Як працює
Обходить усі папки проєкту (крім `node_modules`, `data`, `.git`), для кожного `.js` запускає `node --check`. Якщо в будь-якому файлі синтаксична помилка, команда падає. Інакше пише `syntax ok: N files`.

Запускається в CI (`.github/workflows/ci.yml`) на кожен pull request.

## Обмеження
Це **не повноцінний лінтер**: стиль коду і невикористані змінні не перевіряються.
