# public/style.css

Усі стилі сайту в одному файлі.

## Як влаштовано
- **Змінні кольорів** (`:root`): `--bg` кремовий фон, `--line` темно-жовта/оранжева рамка, `--live` зелений «торги йдуть», `--blue` «ще не почались», `--danger` помилки. Колір по всьому сайту змінюється в одній змінній.
- **Mobile First**: базові стилі для телефона, а `@media (min-width: 640px)` і `@media (min-width: 900px)` додають колонки для планшета й комп'ютера.
- Розділи з коментарями: шапка, кнопки й поля, пошук і фільтри, картки, стани, сторінка лота, форми.
- **Доступність**:
  - `:focus-visible`: видима рамка фокуса при керуванні з клавіатури;
  - `.sr-only`: текст лише для екранних читалок;
  - `.skip`: посилання «Перейти до вмісту»;
  - `prefers-reduced-motion`: вимикає анімації, якщо користувач так налаштував систему.
- **Назва сайту**: рукописний системний шрифт, «Retro» рожевим `#c45f80` (контраст 3,6:1).
- **Сторінка лота на комп'ютері**: висота фото залежить від вікна (`calc(100vh - 290px)`), щоб шкалу часу було видно без прокрутки; панель інформації гортається всередині.

## Пояснення рішень
- **Як перевіряли адаптивність?** DevTools, ширина 375 px: немає горизонтальної прокрутки (методичка 5.2: від 320 px).
