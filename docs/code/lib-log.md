# lib/log.js

Структуровані логи: кожна подія це один рядок JSON.

## Що всередині
- Рівні: `debug`, `info`, `warn`, `error`. Мінімальний рівень задає `LOG_LEVEL` у `.env` (за замовчуванням `info`).
- `log.info('request', { requestId, status, ms })` друкує:
  `{"level":"info","time":"2026-10-30T10:00:00.000Z","msg":"request","requestId":"...","status":200,"ms":3.1}`

## Навіщо JSON, а не звичайний текст
Сервіси збору логів (Grafana Loki, ELK) читають JSON без налаштувань і дають фільтрувати за полями, наприклад «всі помилки з requestId X».

## Пояснення рішень
- **Що не можна писати в лог?** Паролі, cookie, токени, заголовок `Authorization`. Методичка 5.7. Тут вони в лог не потрапляють.
