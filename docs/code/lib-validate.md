# lib/validate.js

Перевіряє вхідні дані на межі сервера. Методичка (5.4): перевірки лише в браузері не зараховуються.

## Що всередині
- **`check(input, schema)`**: перевіряє об'єкт за схемою і повертає **лише описані поля**. Зайві поля від клієнта відкидаються (наприклад, ніхто не підсуне `role: 'admin'`).
  - типи: `string`, `int`, `bool`, `email`, `array`;
  - правила: `min`, `max` (для рядків це довжина, для чисел значення), `optional`, `enum`, `pattern`, `of` (тип елементів масиву);
  - рядки обрізаються від пробілів по краях; рядок з цифрами `"42"` для поля `int` перетворюється на число (так приходять параметри з адреси);
  - збирає **всі** помилки одразу і кидає `fail('validation', ..., { errors: [{ field, rule }] })`. Клієнт підсвічує кожне поле.
- **`luhn(num)`**: алгоритм Луна. Кожна друга цифра справа подвоюється (якщо вийшло більше 9, віднімаємо 9), все додається; справжній номер картки дає суму, кратну 10. Ловить випадкові помилки в одній цифрі.

## Пояснення рішень
- **Чому своя перевірка, а не бібліотека (Joi, Zod)?** Схеми прості і пласкі; 50 рядків замість зовнішньої залежності.
- **Що повертається при помилці?** 400 з масивом `errors`, де для кожного поля вказано правило, яке не пройшло.
