# lots/images.js

Зберігає фото лотів на диск.

## Як фото потрапляє на сервер
1. Браузер зменшує фото до 1600 px і стискає в JPEG (`resizeImage` в `public/app.js`).
2. Фото йде в тілі запиту як **data URL**: рядок `data:image/jpeg;base64,...`.
3. **`saveImages(dataUrls)`** для кожного фото:
   - дозволені лише `jpeg`, `png`, `webp`;
   - розкодовує base64 і перевіряє **«магічні байти»**, справжній підпис формату на початку файлу (JPEG починається з `FF D8 FF`, PNG з `89 50 4E 47`). Файл, перейменований на `.jpg`, не пройде;
   - не більше 3 МБ;
   - зберігає під випадковою назвою (`randomUUID`) у `data/uploads/` і повертає шлях `/uploads/<назва>`.

Папку можна змінити змінною `UPLOAD_DIR` (так роблять тести).

## Пояснення рішень
- **Чому не довіряємо типу файлу від браузера?** Його легко підробити; підпис усередині файлу перевіряє справжній формат.
- **Чому випадкові назви?** Користувач не може перезаписати чужий файл чи підставити шлях на кшталт `../server.js`.
