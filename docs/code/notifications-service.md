# notifications/service.js

Сповіщення на сайті (дзвіночок на аватарці і список у профілі).

## Функції
- **`notify(userId, lotId, type, data)`**: додає сповіщення. Викликається **всередині транзакції** дії: якщо ставка відкотилась, сповіщення теж зникне.
  - `type`: `outbid`, `won`, `sold`, `no_bids`, `paid`, `receipt`, `payment_expired`, `approved`, `rejected`, `cancelled`, `unblocked`;
  - `data`: дані для тексту (назва, сума). Сам текст складає браузер мовою користувача (`n_outbid` і т. д. в `i18n.js`).
- **`list(userId, { page })`**: сповіщення сторінками, нові першими, плюс кількість непрочитаних.
- **`markRead(userId)`**: усі прочитані.

## Чому листи надсилаються не тут
Лист це запит до чужого сервера, він може зависнути або впасти. Тому тут лише запис у базу з `emailed = 0`, а листи надсилає таймер (`notifications/mail.js`). Збій пошти ніколи не скасує ставку чи оплату.
