# notifications/mail.js

Надсилає листи на email.

## Як працює
- Пошту дає бібліотека **nodemailer**.
  - якщо в `.env` є `SMTP_URL` (наприклад, `smtps://логін:пароль@smtp.gmail.com`), листи йдуть справжньою поштою;
  - якщо немає, листи лише записуються в лог (зручно для розробки).
- **`TEXT`**: для кожного типу сповіщення тема і текст українською та англійською.
- **`sendPending()`**: викликається таймером кожні 5 с (`server.js`):
  1. бере до 50 сповіщень з `emailed = 0`;
  2. надсилає лист з посиланням на лот;
  3. якщо надіслати не вдалось, пише попередження в лог і **пробує ще раз** на наступному запуску;
  4. після успіху ставить `emailed = 1`.

## Пояснення рішень
- **Що буде, якщо поштовий сервер недоступний?** Ставки й оплати працюють далі; листи чекають у базі й підуть, коли пошта оживе.
