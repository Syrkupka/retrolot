# admin/service.js

Дії адміністратора.

## Функції
- **`pendingLots(query)`**: черга модерації: лоти зі статусом `pending`, найстаріші першими, з email продавця.
- **`moderate(lotId, { decision, note })`**: `approve` робить лот `active`, `reject` робить `rejected` з причиною. Умова `WHERE status = 'pending'`: двоє адмінів не схвалять і не відхилять один лот двічі. Продавець отримує сповіщення.
- **`cancel(lotId, { note })`**: скасування торгів з порушенням.
  - лише для `active` і `ended`;
  - ставки **не видаляються** (історія незмінна);
  - неоплачений платіж стає `expired`;
  - сповіщення продавцю і всім, хто ставив.
- **`users(query)`**: список користувачів з пошуком за email/іменем і фільтром «лише заблоковані».
- **`setBlocked(adminId, userId, { blocked, reason })`**: заблокувати або розблокувати. Себе заблокувати не можна; іншого адміна теж (`role <> 'admin'`). Після розблокування користувач отримує сповіщення.

## Пояснення рішень
- **Як адмін захищений від звичайних користувачів?** Маршрути `admin/routes.js` стоять за `requireAdmin`; для не-адміна відповідь 404.
