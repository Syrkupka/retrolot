# seed-texts.js

Описи демо-лотів, щоб вони звучали як написані живими продавцями, а не за одним шаблоном.

## Як працює
Функція **`describe(c, pick, rnd)`** складає опис з частин:
1. **звідки річ** (`ORIGIN`): «Знайшов на горищі на дачі...»; буває порожнім;
2. **1-2 деталі категорії** (`DETAIL[c]`): для годинника «за добу відстає хвилини на дві», для книги «дарчий напис 1974 року»;
3. **доставка** (`SHIPPING`): «Відправлю Новою поштою після оплати.»; буває порожньою.

Виходить 2-4 речення. На 200 лотів 192 різні описи.

`pick` і `rnd` передає `seed.js`, тож описи щоразу однакові.

## Як додати свої тексти
Нові речення дописуються в потрібний масив: `ORIGIN`, `SHIPPING` або `DETAIL[номер категорії]` (0 фотоапарати, 1 годинники, 2 платівки, 3 освітлення, 4 меблі, 5 одяг, 6 іграшки, 7 книги). Потім `npm run seed`.
