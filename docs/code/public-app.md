# public/app.js

Увесь інтерфейс сайту в браузері. Це **SPA** (односторінковий застосунок): сервер завжди віддає той самий `index.html`, а цей скрипт сам малює потрібну сторінку і бере дані з `/api` через `fetch`. Без фреймворку, на чистому JavaScript.

## Загальне (початок файлу)
- **`state`**: що треба пам'ятати: мова, хто увійшов, налаштування, різниця годинника з сервером (`skew`), кеш категорій, повідомлення для наступної сторінки (`flash`).
- **`t(key, params)`**: текст поточною мовою з `i18n.js`, підставляє `{name}`.
- **`esc(s)`**: екранує `<`, `>`, `&`, лапки. **Усе, що прийшло від користувачів, проходить через `esc`** перед вставкою в HTML. Це захист від XSS (чужого JavaScript у назві лота).
- **`money`, `fmtDate`, `dur`**: гроші, дати і «2 д 03:12:44».
- **`api(path, opts)`**: один спосіб звертатися до сервера; помилку problem+json перетворює на `Error` з `code` і `data`.
- **`errText(e)`**: зрозумілий текст помилки; для `bid_too_low` підставляє нову мінімальну ставку.
- **`showFieldErrors(form, e)`**: показує помилки від сервера під потрібними полями і ставить фокус на перше.
- **`loadInto(el, fetcher, draw)`**: **три стани** екрана з даними (вимога методички 5.2): «Завантаження...», дані або «Нічого не знайдено», помилка з кнопкою «Спробувати ще раз».
- **`pager`**: кнопки «Назад / Далі» і «Сторінка N з M».
- **`lotPhase(lot)`**: `live` (торги йдуть), `upcoming` (ще не почались), `ended` тощо.
- **`card(lot)`**: картка лота в сітці: фото, назва, ціна, дата, позначка «Торги йдуть» / «Скоро».

## Сторінки
- **`catalogPage`**: головна і «Історія». Пошук з затримкою 400 мс, панель фільтрів, параметри в адресі (можна поділитися посиланням), пагінація.
- **`lotPage`**: сторінка лота:
  - галерея: стрілки поверх фото, мініатюри, зміна фото кожні 5 с (пауза, поки мишка чи фокус у галереї), приближення в 2,5 раза при наведенні;
  - інформація: опис, теги, ціна, крок, ставки, кнопки;
  - **шкала часу**: поки торги йдуть, заповнюється й змінює колір із зеленого на червоний (`hsl(120 → 0)`); до старту синя;
  - **вікно ставки** (`<dialog>`): `Idempotency-Key` генерується один раз на вікно, тож повторне натискання не створить дубль; при `bid_too_low` поле оновлює мінімум;
  - кожні 4 с оновлює дані (`refresh`), поки лот активний і вкладка видима;
  - блоки переможця (продавцю) і даних продавця та скасування торгів (адміну).
- **`lotFormPage`**: створення і редагування лота: перетягування фото, зменшення фото (`resizeImage`), блок автора, кнопка тестового заповнення для адміна.
- **`payPage`**: оплата: дані покупця і картки.
- **`profilePage`**: профіль, сповіщення, список спостереження, мої ставки.
- **`myLotsPage`**: «Мої лоти» з фільтром статусу.
- **`adminPage`**: модерація і користувачі.
- **`authPage`**: вхід і реєстрація, кнопка Google, «Показати пароль».
- **`STATIC`**: Підтримка, Політика конфіденційності, Умови.

## Каркас (кінець файлу)
- **`ROUTES`**: адреса → функція сторінки.
- **`render()`**: знаходить сторінку за адресою, прибирає таймери попередньої (`cleanup`), малює нову.
- **`go(url)`**: перехід без перезавантаження (`history.pushState`). Клік по посиланню з `data-link` перехоплюється.
- **`updateHeader()`**: шапка: вхід або аватарка, меню, кнопка мови, червона крапка непрочитаних.

## Пояснення рішень
- **Як захищено від XSS?** `esc()` для всіх даних користувачів і заголовок `Content-Security-Policy` (скрипти лише з нашого сайту).
- **Чому без React/Vue?** Сайт невеликий; без збірки і залежностей. Методичка дозволяє чистий JavaScript.
