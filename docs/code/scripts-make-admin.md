# scripts/make-admin.js

Видає або забирає права адміністратора. Через сайт цього зробити не можна навмисно: інакше будь-який адмін міг би роздавати права.

## Запуск (у папці Site)
```bash
npm run make-admin -- ivan@gmail.com olena@gmail.com
```
```bash
npm run make-admin -- ivan@gmail.com --remove
```

## Як працює
- Видача: `role = 'admin'`, і користувача одразу розблоковує.
- Зняття (`--remove`): стає продавцем, якщо має лоти, інакше учасником торгів.
- Для кожного email пише результат: `is admin now`, `no longer admin` або `not found`. Людина має спершу зареєструватися на сайті.
- Після видачі прав людині треба вийти й увійти знову.
